# Experiments

Supporting and exploratory notebooks kept for transparency. The **main, complete
pipeline is [`../main.ipynb`](../main.ipynb)** at the repository root — start there.
These are earlier or alternative versions:

| Notebook            | What it is                                                                 |
| ------------------- | -------------------------------------------------------------------------- |
| `colab.ipynb`       | A Google Colab variant of the pipeline (uses `colabcode` to launch a VS Code server in Colab). Same model and approach as `main.ipynb`. |
| `get_data.ipynb`    | Data-loading / event-extraction exploration — the interactive version of the code that became [`../get_data.py`](../get_data.py). |
| `SE.ipynb`          | A scratch notebook for the Squeeze-and-Excitation block.                   |
| `test.ipynb`        | Small ad-hoc test / sanity-check notebook.                                 |

These are **not** cleaned up to the same standard as `main.ipynb` and may contain
rough or incomplete cells. They are preserved so the development process is visible,
but the authoritative results come from `main.ipynb`.
